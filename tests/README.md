# Jira / Xray Acceptance Tests Repository (Gherkin)

This directory contains the **85** verifiable acceptance tests extracted from the repository's **OpenSpec** specifications via `/opsx-extract-tests`.

Each file corresponds to **1 Jira / Xray `Test` ticket** (matching the Adeo Jira schema `ISO-9285`) with:
- **Issue Type**: `Test` | **Test level**: `Acceptance test` | **Sanity check**: `Yes` | **Regression test**: `Yes`
- **Gherkin (`Cucumber`) specification**: `Feature` / `Scenario` / `Given` / `When` / `Then`
- **Bidirectional Jira `Test` links (`tests` ? `is tested by`)**:
  - Linked to its covered **`Sub Use Case`** in [`../requirements/sub-use-cases/`](../requirements/sub-use-cases/)
  - Linked to its parent **`Use Case`** in [`../requirements/use-cases/`](../requirements/use-cases/)
- **Post-Push Naming**: When pushed to Jira via `/opsx-push-jira`, each file is renamed to `<ISSUE_KEY>-<slug>.md` (e.g., `ISO-9285-...`).
